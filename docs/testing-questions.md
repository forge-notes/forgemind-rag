# Testing Questions

这些问题用于演示 RAG 问答效果。实际效果取决于已上传并完成向量化的文档内容。

## 项目说明类

- 项目上传需要注意什么？
- 这个系统支持哪些文件类型？
- 上传后的文件会保存在哪里？
- 文档解析后会生成什么数据？
- 问答历史会保存哪些信息？

## 候选人材料类

- 这个人有哪些技术负责人经验？
- 他熟悉哪些技术栈？
- 他有没有 Docker 和 CI/CD 经验？
- 他有哪些企业系统重构经验？
- 他有没有企业内部系统建设经验？
- 他适合什么类型的软件开发岗位？

## RAG 效果验证类

- 请总结这份文档的核心内容。
- 文档中提到的关键项目有哪些？
- 文档中有哪些可以量化的成果？
- 文档中有没有提到技术架构？
- 文档中有没有提到团队协作或项目管理经验？

## 资料不足验证类

- 文档中是否提到 Kubernetes 生产集群治理经验？
- 文档中是否提到金融风控模型训练经验？
- 文档中是否提到海外支付合规经验？

预期效果：

- 如果知识库中有相关内容，系统应基于来源 chunks 回答。
- 如果知识库中没有足够信息，系统应说明“当前知识库中没有找到足够信息”。
- 回答下方应展示来源引用，包括文档名、页码、chunk index、score 和内容预览。
